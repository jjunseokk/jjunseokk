## 안녕하세요, 프론트엔드 개발자 박준석입니다.

React·Next.js·TypeScript로 웹서비스를, React Native로 모바일 앱을 개발했습니다.

작품 검색과 필터, 대시보드, 예약 화면 등 다양한 서비스 기능을 구현한 경험이 있습니다.
Nest.js와 MySQL로 API·데이터베이스를 구축하고 배포까지 담당하며,
화면과 데이터가 연결되는 서비스 구조를 경험하며 배워가고 있습니다.

또한 사용자가 겪는 불편을 구체적인 기능으로 개선하는 데 관심이 있어
코드 리뷰와 협업을 통해 구현의 이유를 나누고, 유지보수하기 좋은 코드를 작성하고자 노력하고 있습니다.
